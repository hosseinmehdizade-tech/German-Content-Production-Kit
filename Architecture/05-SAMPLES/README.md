# Multi-Type Canonical Sample

`MULTI-TYPE-CANONICAL-SAMPLE.json` با Profile `architecture-proof@1.0.0` شامل:

- 2 Verb با 3 Example به‌دلیل per-Type override
- 2 Nomen، شامل یک Unit چندمعنایی با Sense Registry
- 1 Adjektiv
- 1 Präposition
- 1 Konnektor
- 1 Redemittel
- 1 Nomen-Verb-Verbindung به‌عنوان Primary Learning Unit
- 1 Satzmuster

همچنین `Entscheidung` همان NVV را داخل `connections[]` دارد تا تفاوت Primary Type و Related Connection ثابت شود. Connection kindهای `nvv` و `collocation` جدا هستند، ولی هیچ presentation section در Data تعریف نشده است.

همهٔ ۲۲ Example دارای source آلمانی، Stable ID و translationهای FA/EN همان جمله هستند. نمونه proof معماری است، نه Dataset زبانی certified؛ provenance آن `generated` و `verified=false` است.
