## One approved learner-facing destination

- The learner-facing back MUST NOT create a standalone `Morphologie` or `Morphology` details tile. The canonical semantic object `canonical_unit.morphology` (or equivalent internal typed morphology) is **allowed and must be retained**; a JSON key is NOT a learner-visible tile.
- Inflections not already visible on the exact same effective Vorderseite belong under the established **Formen** detail type. Contextual grammatical restrictions not actually inflections belong in existing **Grammatik** / **Grammatik und Rektion** / **Struktur**, and register notes in **Register**. Do not turn a part-of-speech metadata label such as "Adverb" into a new visible tile.
- Repetition must be judged against the **actually displayed** front for each Study/Quick/Card Design Studio state, never against hidden source or model metadata. Hide only exact-equivalent visible inflections; keep Genitiv, Dativ plural, Imperativ, Konjunktiv II, separability, aux+meaning contrasts, usage restrictions and all hidden-on-front morphology.
- Existing HF2 Vorderseite requirements continue unchanged: source-attested noun articles/plurals, principal verb forms and verified adjective degrees or reviewed no-force status. Preserve plural-only/multi-gender cases and governed construction exceptions. This policy does not authorize a new visible layout/section or alter 15-tile order.
- Never silently delete text because it merely resembles a duplicate. Semantically different use, a parenthetical note, case construction, number constraint or ambiguous source goes to conservative retention/HOLD. Keep old raw items and decisions in a complete reversible sidecar/ledger (or byte-identical parent) before a proposed editable projection removes any redundant learner-facing copy.
- New A2 M1 candidate is a scoped producer-side presentation cleanup; **not** proof the CURRENT app or all producer adapters enforce the rule. Preserve accepted curated-current TSV authority; do not resurrect discarded publisher text. Do not mass-edit historic LOCKED files.
