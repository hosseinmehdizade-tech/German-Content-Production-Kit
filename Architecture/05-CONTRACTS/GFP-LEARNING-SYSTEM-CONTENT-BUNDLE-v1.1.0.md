# GFP Learning System Content Bundle v1.1.0 — v411 Lexical Graph Contract

This contract extends the v1.0.0 semantic bundle for German Flashcards Pro v411. Canonical content remains the semantic source of truth; vocabulary cards are projections.

## Lexical-card rule
Every active lexical **Sense** and every active **Expression** is independently projectable into the normal Wortschatz/card library. Nomen-Verb-Verbindungen and idioms are not a separate practice silo.

For every learner-facing Expression used as a card, production must provide (when the resolved profile requires them):
- `canonical_form`;
- `expression_type`;
- `definition_de`;
- FA + EN translations;
- source/provenance;
- exactly the profile-governed examples (the NVV source profile requires exactly 4 DE examples, each with independent FA+EN translations);
- `structure.pattern_de`;
- `structure.components[]` when the construction can be decomposed safely;
- semantic relations when evidence exists.

## Expression taxonomy
Supported expression types: `multiword_expression`, `reflexive_verb`, `collocation`, `nvv`, `idiom`.

For `nvv`, optional `expression_subtype` may be `funktionsverbgefuege` or `general_nomen_verb_verbindung`. FVG is therefore a subtype of NVV, not a competing top-level type. Idioms remain top-level `idiom`.

## Structure
Recommended expression structure:
```json
{
  "pattern_de":"einen Antrag auf + Akk. stellen",
  "components":[
    {"role":"noun_component","surface":"Antrag","object_id":null},
    {"role":"verbal_head","surface":"stellen","object_id":null}
  ],
  "argument_slots":[{"preposition":"auf","case":"Akkusativ"}]
}
```
`object_id` is nullable. Use it only when the component has a resolved canonical lexical target. Literal components still render in Word Explorer; resolved IDs become clickable graph edges.

## Relations
Supported relation types: `REKTION`, `COLLOCATION`, `RELATED`, `SYNONYM`, `ANTONYM`, `NVV`, `COMPONENT`, `WORD_FAMILY`.

`COMPONENT` may be deterministically projected from `structure.components` when `object_id` is resolved; it does not require a duplicate canonical relation record. `WORD_FAMILY` is an evidence-backed lexical relation. NVV must never be relabeled as Collocation.

## Wortnetz / reverse navigation
Canonical relations are directed facts. The v411 runtime may derive inbound/reverse navigation from canonical outgoing relations and resolved structure components so that a user can move both from an expression to its components and from a component to expressions that use it. Derived reverse navigation is UI/navigation state, not a new canonical linguistic assertion.

## Projection bridge
The v411 vocabulary projection preserves canonical fields in the projected card bridge: `vnext_target_id`, `vnext_target_type`, `vnext_definition_de`, `vnext_translation_fa`, `vnext_translation_en`, `vnext_structure`, `vnext_source_refs`, `vnext_relations`, `vnext_expression_type`, `vnext_expression_subtype`, and `presentation_examples`.

## Examples
Example wording generated by the production pipeline must be original. Reference sources may verify meaning/pattern/naturalness; their example sentences are not copied into flashcards.
